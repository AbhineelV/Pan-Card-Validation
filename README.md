# Pan-Card-Validation

## 📌 Project Overview
This project focuses on validating PAN (Permanent Account Number) records using SQL to ensure data accuracy, consistency, and integrity. The project involves analyzing PAN card details, identifying invalid formats, detecting duplicate records, and checking missing or incorrect values by executing SQL queries. It demonstrates the use of SQL data validation techniques to maintain reliable and accurate datasets.

## 🎯 Objectives
- Validate PAN card numbers based on the standard PAN format.
- Identify invalid PAN card entries using SQL queries.
- Detect duplicate PAN card records.
- Identify NULL values and missing information in the dataset.
- Ensure data accuracy and consistency through SQL validation techniques.
- Generate insights by identifying errors and inconsistencies in PAN card records.

## 🛠 Technologies Used
- SQL
- PostgreSQL
- CSV Dataset

## 📊 Key Analysis Performed
- PAN card format validation using pattern matching.
- Identification of invalid PAN numbers.
- Duplicate PAN record detection.
- NULL and missing value identification.
- Data quality and consistency checks.
- Categorization of valid and invalid PAN records using conditional statements.

## 💡 Key Learnings
- Data validation and data cleaning techniques using SQL.
- Implementation of CASE statements and conditional logic.
- Application of string functions and pattern matching.
- Identification of duplicate records using GROUP BY and HAVING.
- Handling NULL values and missing data.
- Improving data accuracy and maintaining database integrity.
